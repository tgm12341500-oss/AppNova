# AppNova – Modern App Landing Page

A modern, responsive, and visually appealing landing page designed to showcase a mobile application through a clean layout and engaging user interface.

## 🚀 Project Overview

AppNova is a front-end web development project focused on creating an attractive and user-friendly landing page. It features multiple sections that present the application's features, services, pricing plans, customer testimonials, and download options.

## 🛠️ Technologies Used

- **HTML5** – Structuring the web pages.
- **CSS3** – Styling and visual design.
- **Bootstrap 5** – Responsive layout and grid system.
- **JavaScript** – Supporting interactive navigation and Bootstrap components.
- **Font Awesome** – Icons and visual elements.
- **Google Fonts** – Typography and font styling.

## ✨ Key Features

- Responsive navigation bar.
- Modern hero section with a clear call to action.
- Application features and services showcase.
- App screenshots gallery.
- Pricing plans section.
- Customer testimonials.
- Application download section.
- Contact section.
- Responsive layouts for different screen sizes.

## 📱 Website Sections

1. Home
2. Features
3. Services
4. App Screenshots
5. Pricing Plans
6. Customer Testimonials

9. Footer
